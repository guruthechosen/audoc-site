Support

Before requesting help

  1. Keep the original document.
  2. Record the device, OS, file type, app version, selected processor, and exact failed part.
  3. Retry one visual or translated part before restarting all processing.
  4. For cloud errors, test the connection and check provider billing and rate limits.
  5. For local AI, confirm verification completed and the device has enough free storage and RAM.
  6. For speech, confirm the chosen voice supports the script language.

Privacy-safe reports

Do not send confidential files, API keys, or screenshots containing secrets. Include the exact error, approximate file size, slide/page/part number, local or cloud processor, and whether the issue occurs after locking, folding, or reopening the device.

Contact

Contact the developer through the support profile. A dedicated public support channel will be linked from the final store listing.
