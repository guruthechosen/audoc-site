Privacy Policy

Audoc is designed to work locally by default. It does not require an account and does not contain advertising or cross-app tracking. Android’s bundled Google ML Kit performs SDK diagnostics and usage analytics as described below.

Information on your device

Audoc processes files you choose to import, including text, tables, images, charts, diagrams, filenames, and generated listening scripts. It may create language detections, visual descriptions, translations, playback state, checkpoints, and preferences. These normally remain in private app storage and are excluded from cloud device backups.

API keys are protected with Android Keystore or device-only iOS Keychain storage and are not included in backups. You can remove keys, documents, models, and voices in the app.

Optional cloud AI

Cloud processing is off for every document until you enable it. If you enable it and select Google Gemini or OpenAI, Audoc sends only the bounded text batch or visual currently being processed, the required instructions, and your API credential directly to that provider. Audoc does not operate a document-processing server.

Provider security, billing, legal, and retention practices apply. Do not enable cloud processing for confidential material unless your provider agreement permits it. See Gemini API terms, Google privacy, OpenAI API data controls, and OpenAI privacy.

Downloads

Optional model and voice downloads are hosted by Hugging Face or GitHub. Those hosts receive ordinary network information such as IP address, request time, user agent, and requested file. Audoc verifies pinned sizes and SHA-256 hashes before installation.

Android SDK diagnostics

Android uses bundled Google ML Kit for on-device language identification and image labeling. Google collects SDK diagnostics and usage analytics: device/app details, per-installation identifiers, performance and error information, feature events and configuration, input/output sizes, and identified languages. This can occur with local processing even when cloud AI is disabled. Audoc currently has no separate opt-out for this SDK collection.

These diagnostics are distinct from sending document text or images to cloud AI. Google’s disclosure does not list document text or image contents as collected by these bundled features. Google encrypts this data in transit and states that ML Kit does not transfer it to third parties. Google’s retention and deletion practices apply; deleting local Audoc data does not request deletion of data already received by Google. See ML Kit Android data disclosure and Google privacy. The iOS app does not use these ML Kit SDKs.

What the developer receives

The developer does not receive your documents, scripts, translations, API keys, playback history, or prompts through the app. If you contact support, the developer receives only what you choose to provide. Never send confidential files or secrets in a support request.

Retention and security

Local information remains until you delete it, clear app data, or uninstall. Deleting a document removes Audoc's source copy, script, and translation checkpoints. Audoc uses encrypted transport, private storage, backup exclusions, credential stores, and model integrity checks, but no security measure is absolute.

Children and international processing

Audoc is a general productivity app and is not directed to children under 13. Cloud AI and Android SDK diagnostics providers may process data wherever they and their subprocessors operate.
